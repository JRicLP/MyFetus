# Inventário visual atual do MyFetus

Abra [index.html](index.html) no navegador para consultar o relatório preparado como referência de redesign para o Google Stitch.

## Método

- Captura em Expo Web, viewport de 390 × 844 px.
- Telas públicas e da gestante: estado local disponível.
- Telas médicas e prontuário: dados fictícios representativos injetados somente no navegador.
- Nenhum dado de produção foi usado e nenhum código ou registro de banco foi alterado para gerar as imagens.
- `exames-gestante.png` preserva o estado vazio observado sem a API disponível.

As imagens originais estão em [screenshots](screenshots). O HTML funciona localmente, sem servidor e sem dependências externas.
