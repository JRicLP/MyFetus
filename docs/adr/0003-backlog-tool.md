# ADR 0003 — Ferramenta de Backlog

## Contexto

O projeto utilizou diferentes ferramentas para gerenciamento durante ciclos anteriores, incluindo Trello e Jira.

No planejamento do ciclo 2026.2, o GitHub Projects é indicado como ferramenta recomendada para gerenciamento do backlog.

## Decisão

O **GitHub Projects** será utilizado para gerenciamento do backlog do projeto no ciclo 2026.2.

## Consequências

* O backlog ficará integrado ao ambiente do GitHub.
* As tarefas poderão ser acompanhadas e organizadas por meio do GitHub Projects.
* A equipe utilizará uma única ferramenta principal para o gerenciamento do backlog neste ciclo.
