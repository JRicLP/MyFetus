# Termos de Uso do MyFetus — Profissional de saúde

**Versão 0.1-rascunho — 19/10/2026.** RASCUNHO para revisão da gestão do projeto e orientação jurídica. Não é a versão definitiva.

## 1. O que é o MyFetus

O MyFetus é um projeto acadêmico de apoio ao acompanhamento materno-fetal, em desenvolvimento e avaliação pela Equipe MyFetus — ciclo 2026.2. Nesta etapa, destina-se a testes com dados fictícios. **Não insira dados reais de pacientes.**

## 2. Apoio, não decisão

Informações, cálculos, alertas e respostas de inteligência artificial são apoio à decisão e podem conter erros. A conduta clínica é de responsabilidade do profissional. A ausência de alertas não garante ausência de risco.

## 3. Acesso a dados de gestantes

- Você acessa apenas os dados das gestantes com vínculo ativo com você.
- Use os dados somente para o acompanhamento da gestante, mantendo o sigilo profissional.
- O seu aceite destes termos não substitui a autorização da gestante para o tratamento dos dados dela.

## 4. Sua conta

Você é responsável pela veracidade das informações de cadastro (incluindo CRM e UF) e pelo sigilo da sua senha. Não compartilhe o acesso com terceiros.

## 5. Privacidade

O tratamento dos seus dados e dos dados das gestantes está descrito na Política de Privacidade.

## 6. Alterações destes termos

Quando estes termos mudarem, a nova versão será exibida no aplicativo e um novo aceite será solicitado.
